# Trạng thái thực tế

## Đã có

- Đã ghi nhu cầu người dùng thành prompt tiếng Việt và tài liệu kiến trúc, nghiệm thu, lộ trình, quyết định, quy tắc agent.
- File Word cũ được xóa theo yêu cầu người dùng.
- Đây là tài liệu giao việc cho Antigravity; **chưa có mã ứng dụng, dependency app, model AI, test suite app hoặc bộ cài Windows**.

## Cần tiếp tục

1. Đọc prompt và bộ nhớ quyết định, kiểm tra repository/môi trường thực tế.
2. Thực hiện M0 trong `ROADMAP.md`, sau đó tiếp tục các mốc theo cổng nghiệm thu.
3. Dùng fixture tổng hợp do dự án tạo; hai hình minh họa trong chat chưa được cung cấp thành file trong repo.

## Bằng chứng triển khai

| Hạng mục | Trạng thái |
| --- | --- |
| Chạy core raster/vector | Chưa triển khai/chưa chạy |
| Kiểm thử xử lý ảnh và GUI | Chưa triển khai/chưa chạy |
| Build portable Windows x64 | Chưa triển khai/chưa chạy |
| Nghiệm thu trên Windows 11 | Chưa chạy |
| Tích hợp và chạy model AI thực | Chưa chọn/chưa chạy |

Khi coding agent bắt đầu triển khai, thay bảng này bằng tình trạng mới có bằng chứng: mốc/commit, command hoặc thao tác, OS, fixture, kết quả và giới hạn. Không biến “đã viết đặc tả” thành “đã xác minh tính năng”.
